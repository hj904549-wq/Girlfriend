# 💗 Girlfriend — A Little Web Experience

> A fun, interactive website made with love, code, and a little bit of mischief. 💌

Sometimes, a simple **Yes or No** can turn into a whole adventure. 😉

## ✨ Features

- 💕 Interactive buttons and playful surprises
- 🎨 Custom styling and smooth animations
- 📱 Responsive design for different screen sizes
- ⚡ Built with vanilla JavaScript
- 🌸 Multiple pages with a cute, romantic vibe

## 🛠️ Built With

- **HTML5** — Structure
- **CSS3** — Styling and animations
- **JavaScript** — Interactions and behavior

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/hj904549-wq/Girlfriend.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Enjoy the experience! 💗
